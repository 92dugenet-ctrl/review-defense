# V6.37 — PostgreSQL bootstrap readiness

V6.37 prepares the first real PostgreSQL deployment without adding public registration or autonomous external actions.

## Migration

Run: python scripts/migrate.py

It uses DATABASE_URL and the existing src.migration_runner, including migration checksums and advisory locking.

## First OWNER

Set deployment-only variables: DATABASE_URL, BOOTSTRAP_ORG_NAME, BOOTSTRAP_OWNER_EMAIL, BOOTSTRAP_OWNER_PASSWORD and BOOTSTRAP_CONFIRM=CREATE_OWNER.

Run: python scripts/bootstrap_owner.py

The bootstrap is refused when a membership already exists. It creates the organization, user, OWNER membership and a security event atomically.

The password is never printed. Do not paste the password or DATABASE_URL into chat or commit them to GitHub.

This does not create a public signup route and does not bypass MFA or the existing human approval gates for external actions.
