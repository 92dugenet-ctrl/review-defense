# V6.39 — SEO intégré

## Intégration
- 63 URLs publiques issues du pack SEO fourni : 57 pages éditoriales et 6 pages services/conversion.
- Rendu HTML côté serveur via `src/seo_site.py` afin que les contenus publics ne dépendent pas du JavaScript pour être explorables.
- Titles, H1, mots-clés, clusters, CTA et maillage interne issus de l'architecture SEO fournie.
- Canonical, robots.txt et sitemap.xml générés automatiquement.
- JSON-LD : Organization, WebSite, BreadcrumbList, Article/Service et FAQPage lorsque la FAQ est visible.
- `REVIEW_DEFENSE_PUBLIC_URL` permet de définir le domaine canonique réel au déploiement.

## Limite éditoriale
Le ZIP fourni contient principalement l'architecture, les métadonnées et les briefs, pas le corps intégral des 63 articles. V6.39 n'invente donc pas de témoignages, statistiques ou résultats. Les pages publiées utilisent un contenu d'intégration prudent ; les corps éditoriaux complets peuvent être branchés ensuite sans changer l'architecture technique.

## Sécurité
Les pages SEO n'appellent aucune API Google et n'exécutent aucune action externe. Les CTA renvoient vers l'interface Review Defense, où les workflows existants et la validation humaine restent actifs.
