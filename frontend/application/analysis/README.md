# Analysis — pages d'analyse

Regroupe les vues React de l'analyse des avis et dossiers. Les résultats présentés doivent rester traçables aux données et éléments fournis par l'API.

Le frontend ne doit pas contourner les permissions ni calculer une décision d'accès. Préserver les contrats de données, les états d'erreur et les liens vers les dossiers sources.

Structure cible sous `application/`; le routage effectif doit être vérifié dans la configuration Vite et le routeur consommé.
