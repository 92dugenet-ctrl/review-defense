# Settings — paramètres de l'espace

Regroupe la page React des paramètres utilisateur ou organisationnels. Les modifications sensibles doivent être validées côté serveur avec les permissions et le contexte d'organisation appropriés.

Préserver les contrats API, les états de sauvegarde et les erreurs. Structure cible sous `application/`; vérifier le routeur et les imports avant toute migration.
