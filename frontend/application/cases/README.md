# Cases — pages de dossiers

Regroupe les vues React liées aux dossiers : liste et détail. Les règles métier, l'isolation organisationnelle et les transitions restent autorisées et validées par le backend.

Les identifiants d'organisation et de dossier ne doivent jamais être utilisés comme preuve d'autorisation côté client. Préserver les contrats API et les états de chargement/erreur.

Ces pages appartiennent à la structure cible `application/`; vérifier le routeur et les imports Vite avant de les considérer comme le parcours actif.
